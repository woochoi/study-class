# 삭제 요청 처리 절차 (개인정보보호법 제36조)

사용자가 자신의 정보 삭제를 요청하면 운영자가 `delete-user.sql`을 Neon SQL Editor에서 실행한다.

1. Neon 콘솔(https://console.neon.tech)에 로그인해 운영 프로젝트와 브랜치를 선택하고, 왼쪽 메뉴의 **SQL Editor**를 연다.
2. `docs/ops/delete-user.sql` 내용을 편집기에 붙여 넣고, `'user@example.com'`을 요청자 이메일로 **모두** 바꾼다. 따옴표는 지우지 않는다.
3. `-- 1)` 아래 `SELECT`만 드래그로 선택해 실행한다. 사용자 이름이 맞고 `user_match_count`가 `1`인지 확인한다.
   0행이거나 `user_match_count`가 2 이상이면 중단한다. 같은 이메일 사용자가 여럿이면 삭제 블록은 아무것도 지우지 않으니, 사용자 id를 확인해 따로 처리한다.
4. `-- 2)` 아래 `BEGIN;`부터 `COMMIT;`까지를 선택해 실행한다.
5. 3번의 `SELECT`를 다시 실행해 0행이 나오는지 확인한다.

삭제 범위: 요청자의 계정, 세션, 진도, 설정, 질문, 답변. 요청자의 질문에 달린 다른 사용자의 답변도 함께 삭제된다.

처리 후 요청 일시, 요청자 확인 방법, 처리 일시를 운영 기록으로 남긴다. 이메일 외 개인정보는 기록에 쓰지 않는다.
